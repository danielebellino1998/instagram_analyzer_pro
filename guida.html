Come scaricare il file dati da Instagram

Segui questi passaggi dall'app Instagram per ottenere il file ZIP necessario all'analisi.

⚠️ Importante: scegli il formato JSON e solo «Follower e persone/Pagine seguite». Niente foto e video: il file resta leggero e l'analisi è molto più veloce.

Instagram ti avvisa quando il file è pronto: può richiedere un po' di tempo. Una volta scaricato il file ZIP, torna alla pagina dell'Analyzer e caricalo.
